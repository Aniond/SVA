# Minigames and special scenes - installed 0.22

The installed 0.22 scene batch contains **50 texture routes**: nine root-prepared sheets, nine scenery sheets, nineteen locale/international derivatives, two shared-sheet patches and eleven localized cursor routes. Its 739-entry registry and 772-file package passed isolated native checks and normal startup verification. The owned title process was stopped without loading a real farm.

The eleven localized cursor routes carry the same 8,599 changed arcade pixels into language overrides. Their repeated file changes are not additional unique artwork. These routes keep native locale-specific pixels and existing artwork intact.

The 37 dedicated routes cover selected minigame scenes and sprites, seasonal boat journeys, opening backgrounds, photographs, movie scenes and boat artwork. The two shared routes contain selected arcade and mermaid art. They are deliberately partial: surrounding interface art, lettering, earlier approved patches and unrelated sprites remain intact.

Native source inspection resolved 111 dynamic drawing calls for the shared arcade scope. That establishes finite source rectangles, not proof of a successful playthrough. Text, numbers, scoring geometry, title/ending instructions, the ConcernedApe logo and locale-specific differences are protected. Existing Joja character patches also remain exact.

Scenery adds 203,001 changed pixels across nine base sheets; the two shared patches add 16,559. The nine root sheets add 374,259 changed pixels. The nineteen derivatives record 1,361,455 changed file pixels separately in their QA. Locale derivatives reuse approved base artwork while preserving native language differences, so their summed file changes must not be presented as newly authored unique artwork.

Written-PNG validation preserves alpha, hidden RGB, source geometry, protected areas and color relationships. Repeated 16-pixel groups are preservation checks, not universal animation-frame definitions. The scenery preparation avoids periodic tile shading and keeps flat ocean colors and dark shadow shapes unchanged.
