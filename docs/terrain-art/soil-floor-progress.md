# Soil and indoor floors — installed 0.21

Six texture routes are installed in version 0.21, with all 703 texture registrations verified in the normal game. Native validation passed 11,423 soil/floor checks and 103 production player-HD checks. The package contains 736 files.

The three soil atlases preserve dry, wet and snowy connections and change 919, 3,028 and 2,165 pixels respectively. The legacy TileSheets/Floors atlas adds 15,670 restrained interior changes while keeping every tile edge exact. Two actual indoor-floor atlases add 19,940 and 16 changes in previously uncovered regions. The six-route total is **41,738 changed pixels**.

All 115 prior indoor-floor regions remain exact, along with every wallpaper pixel and 16-pixel tile edge. The second indoor sheet has only three small gaps in a very dark pattern; its 16 changed pixels are intentionally modest because protected dark ink remains native. The first indoor sheet changes 185 of 188 eligible quadrants; unchanged edges and protected details are still included safely in coverage.

Already-remade outdoor path artwork is retained. Maps/paths is technical map data and is excluded. TileSheets/Floors is not assumed to be the live placeable-path texture: native Flooring resolves its texture through data. The indoor contracts identify the actual wallpaper/floor pattern routes independently.

Evidence and previews: [legacy floor preparation](../../artifacts/soil-floor-modern/floors/README.md), [indoor floor preparation](../../artifacts/soil-floor-modern/interior/README.md), and `artifacts/soil-floor-modern`. The written-PNG checks preserve native dimensions, alpha, hidden colors, repeated tiles, prior regions and tint relationships. Native data verification covered 88 legacy indoor-floor patterns, nine MoreFloors patterns and thirteen outdoor floor/path definitions; this is not a claim that all terrain or all game artwork is remade.
